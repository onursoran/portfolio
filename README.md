## Projects

### [Vehicle Dynamics & Lap-Time Simulator](https://onursoran.github.io/portfolio/projects/vehicle-dynamics-simulator)
A Python lap-time simulator with a four-wheel vehicle model and combined tire-grip limits, built to compare braking strategies (fixed bias, passive valves and independent wheel braking) on synthetic tracks and real circuits such as Monza. Includes a 112-test suite with analytical checks.
`Python` `NumPy` `Matplotlib` `Vehicle dynamics`

### [Electromechanical Brake Bias System](https://onursoran.github.io/portfolio/projects/electromechanical-brake-bias) · Western Formula Racing
Research and system design for an electromechanical brake-bias adjuster that drives the car’s existing cable adjuster, integrating mechanical, electrical and firmware components within the current pedal-box packaging. *In progress.*
`Mechanical design` `Mechatronics` `Brake systems`

### [Soran Racing](https://onursoran.github.io/portfolio/projects/soran-racing) · Founder & Team Principal
A competitive kart racing team in Canadian regional and national championships: 5 drivers, 11 team members, $15,000+ in sponsorship secured and 9 podium finishes.
`Leadership` `Sponsorship` `Race operations`

## About this repository

This repository is the source code for my portfolio site: a static **React + TypeScript + Vite** app, deployed to **GitHub Pages** by a GitHub Actions workflow on every push to `main`. All content lives in typed data files in [`src/data/`](src/data/).

```bash
npm install
npm run dev      # local development server
npm run build    # type-check and production build
```
